# Anvil

Native Rust AI engineering harness for **Antigravity** and **Claude Code**.  
Zero external runtime dependencies — single stripped native binary embedding `tree-sitter` grammars (TypeScript/JS, HTML/Blade, CSS/SCSS, Python, Kotlin, Dart, Rust, PHP 8.x), an incremental code graph (`anvil-graph`), SQLite FTS5 + Git-safe persistent memory (`anvil-memory`), unified 12-tool stdio MCP server (`anvil mcp`), resident local daemon (`anvil daemon`), tiered verification with content-addressed check caching, conflict-free team task ledger, and hybrid Web/Mobile visual QA.

## What's New in v0.3.0

1. **Targeted Symbol Reading (`anvil graph read-symbol`, `graph_read_symbol`)**: Exact `start_line..=end_line` AST slices (capped at 250 lines) with optional imports via v3 `graph.bin`.
2. **Signature-Only Outlines (`anvil graph outline`, `graph_outline`)**: Token-budgeted file/directory/repo symbol & route outlines without loading implementation bodies.
3. **Tier 1 Content-Addressed Check Cache**: `blake3` scope + manifest hashing in `.harness/.state/check-cache.json` (`--no-cache` to bypass) skips redundant typechecks and tests on unchanged scopes.
4. **Cross-Repo HTTP Route Graph Edges**: Extracts `ExposesRoute` (NestJS, FastAPI, Flask) and `CallsRoute` (Angular `HttpClient`, `fetch`, `axios`, Kotlin Retrofit) for cross-service blast radius.
5. **`tsgo`-First Incremental Typechecking**: Prefers `tsgo` (falling back to `tsc`) with off-repo `--tsBuildInfoFile` stored under `.harness/.state/`.
6. **Heavy-File & Noise-File Token Guard (`PreToolUse`)**: Denies unbounded reads of lockfiles, minified bundles, `dist/`, `node_modules/`, and `graph.bin/json`; emits advisory `InboxMessage` warnings on files > 800 lines.
7. **Resident Local TCP Daemon (`anvil daemon start|stop|status`)**: Holds a hot `CodeGraphEngine` in RAM behind a per-repo ULID token on `127.0.0.1:0` with transparent disk fallback.
8. **Noise-Filtered `anvil diff` & `anvil grep`**: Strips lockfile/noise hunks, annotates touched files with affected symbols, and enforces line/token budgets.
9. **Observability (`anvil stats [--reset]`)**: Tracks hook latency, Tier 1 cache hits, tokens saved (`compressor`, `symbol_read`, `outline`), token-guard triggers, and top rule hits.

## Installation

### Windows (PowerShell)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1
```

Installs `anvil.exe` to `~/.cargo/bin` (or `$env:LOCALAPPDATA\anvil\bin`), ensures `PATH` is configured, and verifies `anvil --version`.

### macOS / Linux

```bash
./scripts/install.sh
```

Installs `anvil` to `~/.cargo/bin` (or `~/.local/bin`) and verifies `anvil --version`.

### Manual Release Build

```bash
cargo build --release -p anvil-cli
```

Release profile uses `opt-level = 3`, `lto = "fat"`, `codegen-units = 1`, `strip = true`, and `panic = "abort"`.

## Architecture (10 SRP Crates)

Every crate is single-responsibility with an acyclic DAG (`crates/`), `unsafe_code = "forbid"`, and a strict `<= 350` line cap per `.rs` file:

| Crate            | Responsibility                                                                                                                                                                                                                                                                                                                  |
| :--------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `anvil-core`     | Config (`.harness/config.json`), shared traits (`SymbolFreshnessProvider`, `OutputParser`), stack detector, diff classifier, content-addressed Tier 1 check cache, noise-filtered `diff_grep`, `stats` telemetry, `N=3` circuit breaker, ratchet engine, git helpers, log compressors, canonical `fs_util`                      |
| `anvil-ast`      | Single-pass embedded `tree-sitter` parser pool (TS/TSX, JS, HTML, CSS, Python, Kotlin, Dart, Rust, PHP 8.x, Laravel Blade), symbol `end_line` spans, HTTP route/call & Laravel view/Inertia extractors, and Tier 0 deterministic rules (`escape-hatches`, `comments`, `strict-types`, `php-hygiene`, `barrels`, `root-hygiene`) |
| `anvil-graph`    | Parallel incremental code graph (`blake3` + `rayon` + `FxHashMap` + `NodeId(u32)` + v3 `postcard`), framework + PSR-4 + HTTP route resolvers, `read_symbol` / `outline`, `tsgo`/`tsc`/PHPStan/Psalm/Pest/PHPUnit runners, label-propagation communities, Tarjan SCC cycles, reverse-BFS blast radius, multi-repo merge          |
| `anvil-memory`   | Local SQLite FTS5 (`rusqlite` bundled) + conflict-free `.harness/memory/chunks/*.jsonl`, progressive disclosure (`search`/`timeline`/`get`/`context`), secret redaction, staleness check via `SymbolFreshnessProvider`                                                                                                          |
| `anvil-mcp`      | Unified JSON-RPC 2.0 `stdio` MCP server exposing 12 `graph_*` and `mem_*` tools with mtime-gated graph/chunk caching and token-savings telemetry                                                                                                                                                                                |
| `anvil-tasks`    | Conflict-free team task ledger (`.harness/tasks/<TASK-ID>/entries/<user>-<ulid>.json`), isolated `plan-<user>.md`, deterministic `tasks.json`, and Git merge driver                                                                                                                                                             |
| `anvil-adapters` | Thin adapter sync and hook translation for Antigravity (`.agents/`, `AGENTS.md`) and Claude Code (`.claude/`, `CLAUDE.md`, `.mcp.json`) via locked `.harness/.state/inbox.json`                                                                                                                                                 |
| `anvil-deps`     | Tier 2 dependency staleness/deprecation audits across npm, PyPI, pub.dev, Maven Central/Google Maven, Cargo, and Composer/Packagist                                                                                                                                                                                             |
| `anvil-qa`       | Hybrid Web (DOM audit script, Playwright capture runner, console/overflow/overlap checks) and Mobile (`adb logcat`, `uiautomator` XML, Roborazzi) visual QA                                                                                                                                                                     |
| `anvil-cli`      | Thin CLI wiring (`clap`), resident TCP daemon (`daemon/`), Token Guard hook, and one module per subcommand                                                                                                                                                                                                                      |

> **CI Note**: `.github/workflows/ci.yml` lives on local branch `chore/ci-workflow` pending GitHub `workflow` OAuth scope before pushing to `origin`.

## Quick Start & Core Commands

```bash
anvil init                                # Initialize .harness/, thin adapters, git merge driver, graph & tasks.json
anvil sync                                # Non-destructively sync .harness/skills/ and adapter configs
anvil doctor                              # Audit config, adapters, JSONC/extends tsconfig, graph, memory, identity, circuit, tools
anvil check                               # Diff-classified Tier 0 / Tier 1 / Tier 2 verification (--full, --tier 0|1|2, --no-tests, --no-cache)
anvil impact <files> --origin <target>    # Reverse-BFS blast radius & upstream origin (--depth 2, --typecheck)
anvil graph build|update|read-symbol|outline|query|path|explain|report|merge
anvil mem save|search|timeline|get|context|sync|check-stale|cleanup
anvil mcp                                 # Start unified stdio MCP server (12 tools: 7 graph_* + 5 mem_*)
anvil daemon start|stop|status            # Manage resident local CodeGraphEngine daemon
anvil diff [--max-lines N] [--max-tokens N]
anvil grep <pattern> [--max-matches N] [--max-tokens N]
anvil stats [--reset]                     # Inspect hook latency, cache hits, tokens saved, token guard & rule hits
anvil tasks start|update|done|plan|build|list
anvil ratchet log|list|review|test|promote # Governed linter rule testing & promotion (triple filter)
anvil circuit status|reset                # Inspect or reset the N=3 Circuit Breaker
anvil deps [--all] [manifests...]         # Audit dependency age/deprecation
anvil qa onboard|select-web|select-mobile|eval-web|run [--phase before|after]|scan-mobile
anvil context pack <targets...>           # Minimal token-budgeted subagent context packet
anvil run -- <cmd>                        # Token-compressed command execution with raw log archiving
```

## Antigravity & Claude Code Integration

Running `anvil init` or `anvil sync` non-destructively configures both agents from `.harness/` as the single source of truth:

- **Antigravity**: `.agents/hooks.json` (`SessionStart`, `PreToolUse`, `PostToolUse`, `PreInvocation`, `Stop`), `.agents/mcp_config.json` (`anvil mcp`), `.agents/skills/`, and `AGENTS.md`.
- **Claude Code**: `.claude/settings.json`, `.mcp.json` (`anvil mcp`), `.claude/skills/`, and `CLAUDE.md`.
- **Unified MCP Tools (`anvil mcp`, 12 tools)**: `graph_impact`, `graph_origin`, `graph_query`, `graph_path`, `graph_explain`, `graph_read_symbol`, `graph_outline`, `mem_save`, `mem_search`, `mem_timeline`, `mem_get`, `mem_context`.
