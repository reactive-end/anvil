# Anvil

**Anvil** is a native Rust AI engineering harness built for **Antigravity** and **Claude Code**.

Packaged as a single native binary with zero external runtime dependencies, **Anvil** enforces deterministic engineering discipline across AI-assisted workflows: tiered verification, multi-language AST analysis, an incremental code graph, progressive-disclosure persistent memory, automatic team task tracking, and strict token-budget control.

## Overview

Instead of relying on bloated prompt instructions or manual verification habits, **Anvil** keeps `.harness/` as the repository's single source of truth and wires directly into the agent lifecycle through thin adapters, hooks, and a unified MCP server.

- **Multi-language & multi-repo:** supports TypeScript/JavaScript, React, Angular, NestJS, Next.js, Astro, Vite, Python, Kotlin/Android, Flutter/Dart, Rust, and PHP 8.x / Laravel (API, Blade, Inertia, and Livewire) across single repositories, monorepos, and umbrella workspaces.
- **Token-efficient by design:** inspects symbol outlines and exact AST slices before reading full files, guards against reading lockfiles/vendor/bundles whole, and compresses compiler and test output into bounded summaries.
- **Evidence-first verification:** combines deterministic AST checks, reverse blast-radius analysis, and targeted execution of each project's native typecheckers and test runners.

## Harness Layers

### 1. Core & Operational Control (`anvil-core`)
Manages repository configuration (`.harness/config.json`), stack and tool detection, semantic diff classification (docs, style, config, logic, contracts, UI, and dependencies), token-bounded output compression, content-addressed Tier 1 check caching (`blake3`), local telemetry, the **`N=3` Circuit Breaker** against blind retries, and the **Ratchet** engine for graduating recurring mistakes into deterministic rules with human approval.

### 2. AST & Tier 0 Rules (`anvil-ast`)
Embeds `tree-sitter` grammars in a single-pass parser pool to extract symbols, line spans, call/import edges, HTTP routes, and template references while running sub-second deterministic Tier 0 checks: blocking unapproved escape hatches, deferred/narrative comments, strict-type violations (`any`, `dynamic`, `declare(strict_types=1)`), PHP/Laravel hygiene issues, pure barrel re-exports, root hygiene violations, and unverified permission assumptions.

### 3. Code Graph & Tier 1 Impact (`anvil-graph`)
Maintains a parallel, incremental binary code graph with native resolution across TSConfig, Angular, NestJS, Python, Kotlin/Gradle, Dart, Rust/Cargo, PHP PSR-4, Blade/Inertia/Livewire, and cross-stack HTTP routes. Powers reverse-BFS blast radius, upstream origin tracing, signature-only outlines, targeted symbol reads, and scoped Tier 1 typecheck and test execution.

### 4. Persistent Memory (`anvil-memory`)
Combines local SQLite FTS5 indexing with Git-friendly JSONL chunks (`.harness/memory/chunks/`) using progressive disclosure (*search → timeline → get*), automatic secret redaction, and staleness detection tied to the live code graph.

### 5. Tier 2 Verification (`anvil-deps` & `anvil-qa`)
- **Dependency Auditing (`anvil-deps`):** audits npm, PyPI, pub.dev, Maven, Cargo, and Composer/Packagist manifests for deprecated, abandoned, or stale (>24 months) packages with TTL caching.
- **Hybrid Visual QA (`anvil-qa`):** pairs programmatic Web DOM and Mobile view-tree checks (Playwright, Chrome DevTools, ADB/`uiautomator`, `logcat`, and Roborazzi) with before/after visual verification.

### 6. Conflict-Free Task Ledger (`anvil-tasks`)
Lazily materializes tracked tasks on the first edited project file and maintains a distributed per-author ULID ledger (`.harness/tasks/` → `tasks.json`) backed by a Git merge driver so concurrent developers and agents never collide.

### 7. Adapters, MCP & CLI (`anvil-adapters`, `anvil-mcp`, `anvil-cli`)
- **Thin Adapters (`anvil-adapters`):** translate lifecycle hooks (`SessionStart`, `PreInvocation`, `PreToolUse`, `PostToolUse`, `Stop`), Token Guard rules, and synced configuration for **Antigravity** and **Claude Code**.
- **Unified MCP Server (`anvil-mcp`):** exposes code-graph and persistent-memory tools over `stdio` JSON-RPC 2.0.
- **CLI & Local Daemon (`anvil-cli`):** provides the terminal interface and an optional resident TCP daemon that keeps the code graph warm in memory.
